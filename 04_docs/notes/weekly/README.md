# 週次ゼミレジュメ

## 概要

毎週のゼミ発表レジュメをここに蓄積します．
Notion での発表と併用し，**このリポジトリを原本**として管理します．

**注意: このリポジトリはテーマ決定後に作成されます．**
テーマ決定前のゼミ発表は Notion のみで管理してください．
リポジトリ作成後の発表から，ここにレジュメを蓄積していきます．

## 運用フロー

1. **ゼミ前**: テンプレートをコピーして内容を記入する
   ```bash
   cp _template.md YYYY-MM-DD.md
   ```
2. **発表時**: 記入した Markdown を Notion にコピーして発表する
   （Markdown をそのまま貼り付ければ書式が保持されます）
3. **ゼミ後**: 質疑メモ・宿題を追記して commit する

## ファイル命名規則

- `YYYY-MM-DD.md`（ゼミの開催日）
- 例: `2026-04-11.md`, `2026-04-18.md`

## なぜリポジトリに残すのか

- 研究の進捗が Git の履歴として残る
- 生成AI（GitHub Copilot 等）が過去の報告内容を参照して支援できる
- 質疑・宿題の履歴を振り返りやすい
- 最終報告書の執筆時に過去の記録を参照できる
